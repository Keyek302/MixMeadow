# Mix Meadow 🎵

A kid-friendly, Sprunki-style music maker. Drop characters into the holes to build a beat, then switch worlds to change the vibe.

## Play
Open the hosted link, or `index.html` in a browser. Works on phones.

## Install as an app
Host it on HTTPS (GitHub Pages is free: **Settings → Pages →** `main` branch, root folder), then:
- **Android (Chrome):** menu → *Install app*
- **iPhone (Safari):** Share → *Add to Home Screen*

After the first visit it works offline.

## How to use
- Drag a tile onto a hole, or just tap it. Tap a character to remove it.
- 🏔️ switches worlds: Meadow, Cemetery, Clouds, Volcano, Parking lot.
- Use the slider for tempo and 🔀 for a random mix.

## Details
- No build step, no dependencies. Sounds are synthesized with the Web Audio API.
- Original characters and art, not taken from any other game.
